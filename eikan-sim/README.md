# 球春 - 高校野球育成シミュレーター

選手育成、日付・年度進行、自動試合、試合記録を備えたブラウザー向けのオリジナル試作です。KONAMIの公式ゲーム画面、音声、選手データは含みません。原作の内部計算式を再現したものではありません。

## 起動

プロジェクトのルートで次を実行し、表示されたローカルURLをブラウザーで開きます。

```powershell
py -m http.server 8000 --directory eikan-sim
```

例: `http://localhost:8000/`

ES Modulesを利用するため、HTMLファイルを `file://` で直接開くのではなくHTTP経由で起動してください。Node.js 20以降でテストできます。外部パッケージのインストールは不要です。

## 操作

- **運営**: チーム練習方針を選び、1日・次の試合・1か月・1年度単位で進行します。画面下部のスタメン欄で各守備位置の選手を選び、上下ボタンで打順を変更できます。能力アップ記録には日付・選手・能力の変化・練習内容を新しい順に表示します。試合日は設定したスタメンで自動試合を行います。
- **選手**: 学年、守備位置、能力、1〜4の弾道、投手能力、投手の変化球、成長・在籍履歴、年度別・通算成績を確認します。投手の個別練習には5方向の変化球取得・変化量アップと第二ストレート取得があり、選手プロフィールで対象球種を選びます。プロフィールから球種の表示名も変更できます。天才選手は育成進捗が1.2倍です。
- **選手一覧**: 野手・投手を切り替えて、それぞれに必要な能力を表示します。学年順またはポジション順で並び替えられます。
- **スカウト**: 毎年度、野手強化9・投手強化9・一芸9・バランス型10・標準型10の地域に都道府県を割り当てます。特色は都道府県選択欄に表示されます。訪問して候補を初めて公開するときにアイテム1個を消費し、候補1人をスカウトするか訪問をスキップします。公開後の再訪にもアイテム1個が必要です。同じ候補への成功率は1回目75%、2回目95%、3回目100%。候補は各都道府県8人で年度中固定、能力は正規分布を模した独自モデルで20〜69です。噂候補は約4%で、そのうち80%が実際の天才です。投手は最大3球種・総変化量9以下。1年度のスカウト入学は最大8人で、ランダム選手を含めて計10人が入学します。勝利でアイテム2個、敗北・引き分けで1個を獲得します。パスコード `pass4150` と個数で補充できます。
- **名字**: 一般的な名字と日本の地名・姓に多い構成要素に加え、提供された名字一覧から読み仮名を除いた表記を取り込んだ18,000種類以上の候補を使用します。重複や判読できない代用表記は除外しています。
- **状態管理**: 疲労の蓄積・回復はありません。投手のスタミナ能力による試合中の消耗は残ります。知名度によるスカウト補正は導入していません。
- **戦績・歴史**: 試合を選ぶと全スタメンの打撃成績、投手成績、イニング別スコアを確認できます。個人成績の選手名から選手プロフィールを開けます。年度記録、卒業生の成績も確認できます。
- **保存**: ブラウザー内に毎回自動保存し、直前の保存データをバックアップします。JSONで保存・読込ができ、選手一覧はCSVに出力できます。
- **再現性**: 新規開始時に乱数シードを指定できます。同じシード、同じデータ、同じ進行操作で同じ結果を再現します。

## テスト

```powershell
npm.cmd test
```

Node.js標準のテストランナーを使います。依存パッケージはありません。

現在のセーブ形式はschema v7です。以前のセーブは読み込み時に移行されます。v6までの候補投手データで球種が旧形式またはフォーク1球種に固定されている場合、年度・候補IDに基づく固定シードで球種を再生成します。

実装済みの範囲、推定式、未実装項目、開発段階は [DESIGN.md](./DESIGN.md) を参照してください。
